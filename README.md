# Would You Rather...

A web-based **Would You Rather** game built with Django. Players will be presented with two choices and must decide which option they would rather choose.

*_Still under development_*

**Future planned features**
  * [x] Choices
  * [ ] Global percentage counter
  * [ ] Random question shuffle
  * [ ] Question Suggestions 
  * [ ] Comments to tell user stories based on the question
  * [ ] Admin interface to manage questions
  * [ ] User registration
  * [ ] Users Adding questions themselves

**Updates soon**

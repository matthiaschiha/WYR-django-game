About Would You Rather

Would You Rather (WYR) is an interactive web application inspired by the popular Would You Rather game. It invites users to explore hypothetical scenarios and choose between two difficult, funny, or thought-provoking options.

Each scenario presents two choices. Users can vote for their preferred option and view the results, including vote counts and percentages, to see how their choices compare with other votes.

About the Project

This project was built to develop my skills in Python, Django, database management, and web development. It also gave me practical experience deploying a web application for public access.

The application uses SQLite during local development and PostgreSQL in production. It is hosted on Render, with WhiteNoise serving static files.
